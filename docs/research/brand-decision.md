# Groundlane 品牌決策

日期：2026-08-21

決策狀態：**已確認採用 Groundlane**（2026-08-21）。

## 正式品牌：Groundlane

含義：為 AI agent 提供一條通往可驗證、可引用 Web context 的受控路徑；`ground` 同時對應 grounded answers，`lane` 對應 provider routing。

品牌架構：

- Groundlane Search
- Groundlane Reader
- Groundlane Research
- Groundlane MCP

`Groundlane Browser` 僅用於內部 browser execution engine 的技術稱呼，不作為獨立公開產品線。

定位句：

> The trusted web access layer for AI agents.

技術描述：

> Search, read, browse, and research the web through one secure, observable interface.

套件候選：`groundlane`、`groundlane-mcp`、`@groundlane/sdk`。

2026-08-21 初步檢查：GitHub repository exact-name search 無 `Groundlane` repository；npm 的 `groundlane` package 顯示 not found。這不等同商標或網域可用，正式採用前仍須查主要市場商標、公司名、網域與社群帳號。

## 次選

1. **Citelane**：最適合 research/citation-first 產品，但對 browser automation 的涵蓋感較弱。GitHub exact-name repository 與 npm package 初查皆未見。
2. **Weblane**：一眼能懂，但過於描述性，品牌辨識與商標保護較弱。
3. **Context Relay**：能涵蓋非 Web 資料，但 AI 市場同質名稱較多，個性較弱。

## 建議命名決策

- 公司／公開品牌：Groundlane
- 產品類別：agent web access layer
- browser engine：Groundlane Browser（僅內部技術名稱）
- MCP server：Groundlane MCP
- 工具名稱維持通用：`web_search`、`web_fetch`、`web_extract`、`web_crawl`、`web_research`、`browser_session`
