# Open-source project breakdown for Groundlane

Updated: 2026-08-30.

This breakdown expands `docs/research/open-source-references.md` into product and
architecture patterns Groundlane can use. It does not treat stars, rankings, or
awesome-list placement as adoption reasons. Those signals only explain why a
project was discovered.

Confidence labels:

- `confirmed`: checked against an official repository or documentation page in
  this research pass or in the source reference document.
- `inferred`: inferred from official README/docs shape, architecture, or API
  examples, but not yet verified by reading implementation internals.
- `discovery-only`: candidate came from a catalog/topic/list/trending source, or
  only a shallow official page check exists.
- `blocked`: source, license, runtime, or provider evidence is insufficient.
